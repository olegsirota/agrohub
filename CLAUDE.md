# agrohub — заметки для Claude Code

Лендинг АгроХаба (React + Vite + Tailwind, статика на GitHub Pages). Как собирать и где что лежит — в `README.md`.

## Реклама (Яндекс Директ, VK Реклама)

- Утилита: `npm run ads -- <direct|vk|check> …` (`scripts/ads/ads.mjs`). Справка: `npm run ads -- --help`.
- Настройка доступов и переменные окружения: `scripts/ads/README.md`.
- **Перед любой работой с кабинетами нужен рабочий контекст** (ID кабинетов и кампаний, правила ведения, формат ежедневной сводки, открытые вопросы). Репозиторий публичный, поэтому он хранится не здесь, а на Google Диске Олега: папка «Fable 5 — база знаний» → `01_БАЗА_ЗНАНИЙ` → файл `РЕКЛАМА_КОНТЕКСТ.md` (искать через коннектор Google Drive по названию). В начале сессии скачать его в `scripts/ads/CONTEXT.md` (файл в `.gitignore`, в git не попадает). После существенных решений (запуск/остановка кампаний, смена бюджетов, новые правила) обновлять файл на Диске.
- Бюджеты и статусы кампаний менять только по явной просьбе Олега; сводки и анализ — свободно.
- Общение с Олегом — по-русски, кратко, цифры в таблицах.
