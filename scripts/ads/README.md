# Управление рекламой: Яндекс Директ и VK Реклама

`scripts/ads/ads.mjs` — консольная утилита, через которую Claude Code (или вы сами) смотрит
статистику и правит кампании в двух кабинетах. Зависимостей нет, нужен только Node 18+.

```bash
npm run ads -- check                       # проверить доступ к обоим кабинетам
npm run ads -- direct campaigns            # кампании Директа
npm run ads -- direct stats --period LAST_7_DAYS
npm run ads -- direct suspend 12345678     # остановить кампанию
npm run ads -- direct budget 12345678 1500 # дневной бюджет 1500 ₽
npm run ads -- vk campaigns                # кампании VK Рекламы
npm run ads -- vk stats --from 2026-10-01 --to 2026-10-12 --by-day
npm run ads -- vk daily                    # ежедневная сводка по группам (вчера, накопленно, % лимита, вердикт)
npm run ads -- vk stop 987654              # остановить кампанию VK
npm run ads -- vk budget 987654 --day 1000
npm run ads -- --help                      # все команды
```

Токены читаются из переменных окружения или из файла `.env` в корне репозитория
(он в `.gitignore`, образец — `.env.example`). **Никогда не коммитьте токены.**

Рабочий контекст (ID кабинетов и кампаний, правила ведения, формат сводки) хранится
**вне репозитория** — репозиторий публичный. Файл `scripts/ads/CONTEXT.md` в `.gitignore`;
где его взять, написано в `CLAUDE.md`.

## 1. Яндекс Директ

### 1.1. Доступ к API Директа

1. Откройте Директ под логином, которому принадлежат кампании.
2. Инструменты → **API** (или прямая ссылка `https://direct.yandex.ru/registered/main.pl?cmd=apiSettings`) → подать заявку на доступ к API.
   Для собственного кабинета заявка обычно одобряется за 1–2 рабочих дня. Пока ждёте — можно
   работать с песочницей (`YANDEX_DIRECT_SANDBOX=1`), там же включается тестовый кабинет.

### 1.2. OAuth-приложение и токен

1. Зайдите на `https://oauth.yandex.ru/client/new` и создайте приложение
   («Для доступа к API» / веб-сервис).
2. Права: **«Яндекс Директ» → «Использование API Яндекс Директа»** (`direct:api`).
3. Redirect URI: `https://oauth.yandex.ru/verification_code`.
4. После сохранения скопируйте **ClientID** приложения.
5. Откройте в браузере под нужным логином Директа:
   ```
   https://oauth.yandex.ru/authorize?response_type=token&client_id=<ClientID приложения>
   ```
   Разрешите доступ — на странице покажут токен. Он живёт год, после истечения повторите этот шаг.

Переменные:

| Переменная | Что это |
|---|---|
| `YANDEX_DIRECT_TOKEN` | OAuth-токен из шага 5 (обязательно) |
| `YANDEX_DIRECT_CLIENT_LOGIN` | логин клиента, **только если** токен выдан агентскому логину |
| `YANDEX_DIRECT_SANDBOX` | `1` — работать с песочницей `api-sandbox.direct.yandex.com` |

Что умеет скрипт: список кампаний с балансом и бюджетом, отчёт по кампаниям (расход, клики, CTR,
конверсии; за период или по дням), остановка/запуск, дневной бюджет, фразы со ставками,
а также `direct raw` для любого метода API (например, `bids set`, `adgroups update`).

Нюансы Директа:
- деньги в API — в микроединицах (×1 000 000); скрипт переводит сам;
- дневной бюджет можно менять ≤3 раз в сутки и только на ручной стратегии; у автостратегий — недельный бюджет (`WeeklySpendLimit` через `direct raw campaigns update`);
- ЕПК (единые перфоманс-кампании) обслуживаются через версию `v501` — скрипт выбирает её сам.

## 2. VK Реклама (ads.vk.com)

### 2.1. Доступ по API

1. В кабинете VK Рекламы: **Настройки → Доступ по API** (`https://ads.vk.com/hq/settings/access`).
2. Создайте доступ — получите **client_id** и **client_secret**.
   Если вы работаете через агентство/менеджерский кабинет, дополнительно понадобится
   числовой id клиента (`VK_ADS_AGENCY_CLIENT_ID`).

Скрипт сам получает токен по `client_credentials`, кэширует его на сутки
(`~/.cache/agrohub-ads/vk-token.json`) и при превышении лимита в 5 токенов удаляет старые.

| Переменная | Что это |
|---|---|
| `VK_ADS_CLIENT_ID` | client_id из «Доступ по API» |
| `VK_ADS_CLIENT_SECRET` | client_secret оттуда же |
| `VK_ADS_AGENCY_CLIENT_ID` | id клиента для агентского доступа (необязательно) |
| `VK_ADS_TOKEN` | готовый access_token — если задан, client_id/secret не нужны |

Что умеет скрипт: кампании (ad_plans) и группы, статистика (по кампаниям/группам/объявлениям,
суммарно или по дням), ежедневная сводка `vk daily` в формате прежних утренних отчётов
(по каждой группе вчера и накопленно, % дневного лимита, статусы модерации, вердикт по CPC и CTR;
поле goals не учитывается — для клипов оно техническое), остановка/запуск кампаний и групп,
бюджеты, `vk raw` для любого запроса.

> Старый кабинет «Реклама ВКонтакте» (`vk.com/ads`, API `ads.*` на `api.vk.com`) этот скрипт не
> трогает: новые кампании ведутся в VK Рекламе. Если нужен и старый — добавим отдельный режим.

## 3. Настройка облачного окружения Claude Code

Чтобы Claude мог вызывать API прямо из сессии, в настройках окружения (меню окружения в
заголовке сессии → Edit) нужно:

1. **Network access → Allowed domains** добавить:
   - `api.direct.yandex.com` (и `api-sandbox.direct.yandex.com`, если нужна песочница)
   - `ads.vk.com`
2. **Network secrets / Environment variables** задать переменные из таблиц выше
   (минимум `YANDEX_DIRECT_TOKEN`, `VK_ADS_CLIENT_ID`, `VK_ADS_CLIENT_SECRET`).

Новая сессия подхватит их автоматически. Первым делом запустите `npm run ads -- check`.

## 4. Локально

```bash
cp .env.example .env   # вписать токены
npm run ads -- check
```
